# Broadside Baron candidate

Final source: `build_cp_broadside_baron.py`. Final exported model: `cp_broadside_baron.glb`; packed editable scene: `cp_broadside_baron.blend`.

Used **3 of the maximum 8 harness iterations**. All three passed the size, pivot, ground clearance, textures and clip contracts. Iteration 1 established the complete four-cannon airship and named clips. Iteration 2 widened the porcelain bow, strengthened navy/brass balance, enlarged cannon cheeks, and added a short signal mast. Iteration 3 replaced the separate honey-yellow lens centre with a smoothly graded procedural amber lens texture. Final comparison inspected: `renders/iter03/compare.png`.

Final imported audit: **43,196 triangles, 6 mesh objects, 6 used materials**, four generated 1024 x 1024 textures embedded in the **3,944,436 byte GLB**. Bounds: **3.197 x 3.092 x 1.952 m**, lowest point **0.200 m**, horizontal bounds centre `(0, -0.056)` m. The triangle target is advisory; this boss exceeds 18,000 triangles because its continuous egg silhouette, four rounded cannon housings, bevelled machined collars, curved longitudinal ribs and circular brass hoops retain smooth outlines. Static geometry is joined per rigid part to reduce mesh object count. A selective tessellation reduction can follow visual acceptance.

Exactly four independently addressable corner gun pivots: `Cannon_FL`, `Cannon_FR`, `Cannon_RL`, `Cannon_RR`. At rest they point diagonally outward with local +Y along the actual barrels. Blender Z yaws: +45, -45, +135, -135 degrees respectively. Pivots have advisory custom metadata for a 120 degree firing sector (±60 degrees). Runtime must enforce those limits. Muzzle marker nodes `Muzzle_FL/FR/RL/RR` are placed at `(0, 0.775, 0.03)` in their corresponding `Recoil_*` child, so the tip follows recoil. Godot conversion makes local -Z the firing axis. No legs or tall tail fins. The only aft paddles are the four rotating propeller blades.

Rigid transform clips exported and checked by `audit_export.py`: **Idle 2.000 s**, **Walk 1.600 s**, **Swim 1.600 s**, **Attack 1.033 s**. Idle/Walk/Swim combine hull bob, subtle cannon sway and propeller rotation. Attack adds short staggered recoil on all four guns and returns to rest. All clip endpoint transforms match (rotations compared modulo quaternion sign), so the movement clips can loop without a transform seam. GLB does not encode gameplay looping policy; set Idle/Walk/Swim to loop and Attack to one-shot in Godot. `export_audit.json` records clip/channel counts and marker nesting.

Remaining limitations versus the concept: the reference's tall stern fins are intentionally omitted per user correction; rear-corner gun arrangement and the stern propeller are invented from the single view. The model has cleaner, more regular enamel regions and less hand-painted highlight variation than the illustration. Materials use subtle procedural finish and physically lit highlights rather than painted illustration lighting. No baked ambient occlusion or normal maps. The brighter amber lens is still softer than the reference's luminous yellow eye under the neutral checker lighting. Godot import/playback and gameplay-distance validation are assigned to the parent task because this task may write only its own run folder.

Honest visual self-score: **8/10** for the requested corrected silhouette and polished procedural build. Runtime verification remains a separate acceptance check. No frame-time or performance claims.
