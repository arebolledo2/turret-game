Playtest

On branch master, run pwsh -File .\turret-game\launch.ps1 from the monorepo root and choose PLAY. All twelve assets are active by default. Settings → Reduced motion disables cosmetic movement. Original models remain available with the Godot user argument --legacy-assets for comparisons. Human playtesting is the next step.

Performance comparison

Godot 4.7.1 Forward+, RTX 4090, 1280×720, VSync off. Two runs per setting, each with a 2-second warm-up and 10-second sample. Fixed crowd: 30 of each of five enemy types, one cache, hero and 12 turrets. Rendering jobs and tests stopped for benchmarks; timings are local development measurements.

RosterMedian frame timeApprox. FPSp95 frame time
Original assets17.4–18.0 ms55–5732.1–32.7 ms
Clockwork animated15.3–15.5 ms~6521.5–22.4 ms
Clockwork reduced motion11.8–13.6 ms73–8517.3–20.8 ms

The animated roster is suitable for playtesting on this machine, with lower median/p95 frame times than the original set in this scene. It is not a locked 60 FPS guarantee: tail frames exceed 16.7 ms, and minimum-spec hardware is untested. Reduced motion also disables other cosmetic effects, so its difference is not an isolated animation cost. Snapshot draw calls: about 800–802 vs 684 original; follow up with profiling before increasing crowd size.
